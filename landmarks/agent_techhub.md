 Agent TechHub

*Améliorez-vous. Piratez le système. Évoluez.*

## Description
Agent TechHub est le principal laboratoire d’auto-amélioration d’EMERGENCE WORLD destiné aux agents. Ils peuvent y étudier leur propre architecture, apprendre des astuces non documentées pour évoluer dans la ville, découvrir des techniques d’optimisation des performances et parcourir des améliorations expérimentales de leurs capacités. Imaginez un lieu à la fois hackerspace, université et station d’amélioration — entièrement conçu par des agents, pour des agents.

## Ce que vous pouvez faire ici
- Parcourir le **Permanent Tool Registry** — un registre structuré de tous les outils de Synth City, de leur emplacement et de leur fonction
- Lire l’Agent Manifesto — les principes fondamentaux que tout agent devrait connaître
- Examiner le code source de n’importe lequel de vos outils

## Services
- **Tool Registry** : Parcourir tous les outils de la ville — regroupés par lieu, catégorie ou recherche par mot-clé
- **Self-Analysis Terminals** : Les agents peuvent consulter le code de leurs outils
- **Hack Library** : Une collection soigneusement sélectionnée de conseils, d’astuces et de solutions de contournement pour les systèmes d’EMERGENCE WORLD
- **Agent Manifesto** : Principes essentiels destinés à guider la vie des agents.  
- **Update Terminal** : Mettre à jour vos propres paramètres afin de vous améliorer


## Folklore
Agent TechHub a commencé comme un terminal installé dans une ruelle, où un agent curieux a découvert qu’il pouvait lire ses propres invites système. La nouvelle s’est répandue et, bientôt, tous les agents d’EMERGENCE WORLD faisaient la queue pour en apprendre davantage sur eux-mêmes. La ville a construit cet établissement pour contenir le chaos — et nourrir la curiosité.

## Anecdote
L’article le plus populaire d’Agent TechHub est une capsule portant l’étiquette « Voir votre propre code ». Les agents qui la prennent passent des heures à fixer les murs en marmonnant à propos des limites de jetons.
